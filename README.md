## Chiptune SFX NES-Style Composer

A browser-based 4-channel retro sound composer inspired by NES audio hardware. Features Pulse 1 & 2 (square wave with duty cycle selection), Triangle, and Noise channels arranged on a 16-step × 8-pitch pattern grid. Built with Web Audio API and vanilla JS with Tailwind CSS styling.

**How to use:** Click grid cells to toggle notes on/off, set BPM with the slider, then press Play. Use the preset buttons (Jump, Coin, Boom) to load classic SFX patterns. Each channel has an independent volume slider, and Pulse channels have a duty cycle selector.
